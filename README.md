# Student Management System

A C++ based Student Management System that uses Object-Oriented Programming (OOP) and file handling to manage student records.

## Features

- Add new student records
- Display all student records
- Search for a student by ID
- Update student information
- Delete student records
- Store student data using file handling

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- STL Vector

## How to Run

1. Compile `student_management_system.cpp` using a C++ compiler.
2. Run the generated executable.
3. Use the menu to add, display, search, update, or delete student records.

## Data Storage

Student records are stored locally in `studentRecord.txt`.

The data file is excluded from this repository using `.gitignore`.
